## 2. 项目目标与比赛约束

- 面向温医大校园的兴趣社交与活动产品，以兴趣、个性、自我表达和社交目的帮助认识人并共同参与活动。“同频 Campus”作为当前工作名称，不宣称最终命名已定。
- 交付形态：**响应式 Web 网站**，普通浏览器直接访问；Mobile-first，保留类似 App 的移动交互，同时适配电脑浏览器。最终提供真实线上网址，以及完整源码与本地启动方法；两项独立验收，不能互相替代。
- 不以原生 Android/iOS、APK/IPA、应用商店发布或必须安装的移动应用为目标。PWA、Service Worker、离线安装仅为待评估增强项，不作为起步或交付强制依赖。
- 赛题 6；WorkBuddy 完成主体开发和实际部署，其他 AI 工具辅助规划、审查和文档维护。保留真实提示词、生成结果、人工调整和否决记录，不伪造开发来源。
- 非颜值优先、非 Tinder 式滑卡；MBTI/星座仅辅助表达，不作科学相容性承诺。
- 官方要求基本内容过滤；不出现色情、暴力、人身攻击。演示使用合成资料，不采集真实个人信息，不使用真实患者数据或未脱敏师生敏感数据。
- 官方最终交付：作品说明文档、三分钟以内露脸创作自述、三至五分钟功能演示、可本地运行的源码包与运行说明。格式、体积、命名、百度网盘永久分享和最终 ZIP 的 SHA256 以 `references/official/提交材料说明.md` 为准；源码包不含 `node_modules`。
- 官方允许已部署作品附访问链接；**必须最终线上可访问是 DEC-005 的团队新增要求**。WorkBuddy 应将真实网址和部署/数据限制写入运行说明及作品说明材料，并保证评审期间可访问；不能把官方的可附链接表述误写为本项目可不部署。

## 6. 已确定的交互与状态边界

### 6.1 Portrait

先浏览 → 需要互动时补充基础 Portrait → 校验昵称、至少一个兴趣、至少一项社交意图 → 预览 → 用户选择非公开保存或明确公开。自由文字、MBTI、星座、关系状态不作为必填。

“基础资料完整”和“已公开”是两个独立条件；预览不等于公开。公开后可撤回，公共列表和星云同步排除该用户；已有互动不跟随删除。

| 条件 | 浏览公开资料/活动 | 主动打招呼 | 报名资格 | 公共找人/星云展示 |
| --- | --- | --- | --- | --- |
| 未完成基础 Portrait | 允许 | 先创建 | 先创建 | 不展示未公开资料 |
| 基础完整、未公开 | 允许 | 不允许，需先公开 | 允许，需向组织者展示基础 Portrait | 不展示 |
| 已公开 | 允许 | 具备公开门槛，其他招呼规则未定 | 具备资料门槛，审核等另定 | 展示已确认公开内容 |
| 撤回公开 | 允许 | 暂停主动发起 | 已有报名保留，也仍允许未公开身份报名 | 不展示 |

上表的“报名资格”不等于提交成功或自动入队。未建 Portrait 也不等于已确定采用免登录、匿名身份或某种认证方式。

### 6.2 邀请与会话

正式规则为：打招呼 → 待处理邀请 → 接收方明确接受 → 开启自由聊天。第一阶段可使用固定合成邀请演示“接受”这一已确认转换，不提前完成未定的发送规则。

拒绝邀请是最后一个尚未回答的问题；“接受/拒绝”双按钮仅是 Codex 建议。不得据此添加已确认的拒绝状态、拒绝通知、重新邀请冷却时间或自动应答。邀请文字是否必填也未决定。

### 6.3 撤回与已有互动

撤回只改变已确认的公开发现/主动打招呼条件，不自动取消邀请、会话、活动报名。已有邀请接收者、会话对方、活动组织者仍能从记录查看基础 Portrait；其他用户不能借普通公共入口读取未公开资料。

报名由用户单独取消已确认；取消期限、界面、名额回补及入队后的退出规则未定。本阶段用已有记录验证“撤回不取消”，不借此定义完整取消流程。

互动中查看当前资料还是提交时版本未定。第一阶段使用固定的互动资料样例、不演示互动后编辑，避免无意选定版本语义。公共资料可见范围与资料版本应分别封装，后续可替换。

## 7. 数据模型与模拟数据

以下为 **Codex 建议的最小工程契约**，字段名、类型和存储方案尚未冻结；WorkBuddy 主 Agent 在派工前统一。不得把建议模型直接当作生产 API 或认证方案。

| 模型 | 第一阶段所需信息 | 边界 |
| --- | --- | --- |
| DemoIdentity | 合成标识、显示名、当前演示上下文 | 身份不等于 Portrait；不采集学号、手机号、真实认证信息 |
| Portrait | 所属标识、昵称、兴趣列表、社交意图列表、可选自由文字/MBTI/星座/关系状态、公开标记 | 完整性可由字段计算；空关系状态不推断单身；不把关系状态并入社交意图 |
| PublicPortraitView | 由预览确认的公开内容 | 公共列表、公共详情和星云共用公开范围；不暴露未确认公开字段 |
| InteractionAccess | 关联邀请/会话/报名、可查看者、对应基础 Portrait | 定向授权独立于公开标记；客户端样例判断不是生产安全认证 |

| Conversation | 参与者、关联已接受邀请、展示用内容 | 自由聊天入口受接受状态控制；不宣称已实现实时传输 |
| Activity | 合成标识、标题、说明、兴趣类别、示例时间/地点、组织者 | 字段为活动展示建议，不表示发布必填、容量或时间协调规则已定 |
| EnrollmentFixture | 活动、报名者、组织者、已有报名记录 | 用于展示/验证已有关系；不将记录直接解释为已审核或已入队 |
| NebulaProjection | 公开用户标识、显示标签、可选示例位置 | 从公开资料派生；不保存一份会泄露撤回用户的独立缓存 |
