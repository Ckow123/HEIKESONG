## 采用的设计原则

1. 先明确产品目的、受众、语气、技术约束和记忆点，再实施界面。
2. 以明确且一致的视觉方向贯穿页面，重视字体层级、色彩变量、空间构成、背景细节与交互反馈。
3. 通过真实的 React / TypeScript / Tailwind 代码实现生产可用、细致且协调的界面，而非静态效果图。
4. 避免通用模板感、无意义装饰、平均用色和缺乏校园语境的组件组合。
5. 动画与复杂度服从视觉目标；本项目采用克制的 CSS 微交互，不引入新依赖。

## 受项目约束调整的原则

- 不追求脱离产品语境的极端风格；采用「清新校园刊物感 + 轻盈社交卡片」作为明确方向。
- 不更换已确定色板：primary `#6C5CE7`、mint `#3ECFAD`、pink `#F47FB0` 及其浅底、页面/文字 tokens 全部保留。
- 不采用全站紫渐变、过重背景纹理、大面积毛玻璃或夸张动画；深色 `#1B1437` 仅用于局部星云横幅。
- 字体沿用项目已确定的中文栈，不额外下载字体或安装依赖。
- 空间构成服务于移动端优先、桌面完整布局、信息清晰和 40–44px 触控目标，不为了不对称而破坏可用性。
- 四栏导航、页面信息架构、公开投影与 B1 隐私规则优先于任何视觉建议；不新增业务字段、按钮或交互。
