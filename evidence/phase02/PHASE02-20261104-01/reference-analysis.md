## 1. 同频校园发现主页.png（移动端）

- **视觉与布局**：校园插画 Hero 建立第一记忆点；大标题两行，关键词用主紫色强调；搜索框与 Hero 重叠衔接；双入口并排，淡紫/薄荷区分；整行深紫星云横幅形成节奏断点；下方人物双列与活动纵向列表。
- **颜色与卡片**：白底为主，浅紫、浅薄荷作功能色，深紫只用于星云；卡片白底、轻阴影、中大圆角，封面图提供内容识别。
- **字体层级**：Hero 标题最大且粗，分区标题次之，卡片昵称/活动标题为中等等宽粗体，元数据更小、更低对比。
- **借鉴**：首屏叙事顺序、双入口色彩语义、星云横幅的视觉吸引、人物封面与头像层次、活动元数据对齐。
- **不照搬**：学院/年级等资料字段、装饰性互动；不以插画替代真实 React 组件。

## 7. 同频 Campus 星云探索界面.png（仅提取横幅语言）

- **视觉特征**：深紫空间、大小不同的柔和行星、细轨道与局部光晕，浅色文字和白色入口形成对比。
- **用于发现页横幅**：保留整行比例，以左侧标题/说明、中央少量行星与轨道、右侧箭头构成清晰焦点；控制装饰数量，避免压过双入口与推荐内容。
- **明确不采用**：本阶段不重构 `/nebula`，不新增拖动、缩放、搜索、筛选、侧资料联动或 Three.js 建模。

## 与 Design Tokens 的融合及统一方向

- 方向定义为「**清新校园刊物感**：校园叙事 Hero + 轻盈社交卡片 + 局部星云深色节拍」。
- 保留所有既定 tokens；紫色负责品牌与主操作，薄荷负责活动/积极状态，粉色负责温暖提示，浅色底用于分区而非全站渐变。
- 卡片统一约 18px 圆角、细边界与轻阴影；用间距、标题和细分隔线代替卡片套卡片。
- 字体沿用现有中文栈：页标题 24–32px 响应式、分区标题 17–20px、卡片标题 14–16px、元数据 12–13px；保持正文行高与标签换行。
- 通过 Hover 轻微抬升、Active 回弹、Focus 清晰环和减少动态偏好支持改善反馈；不引入新动画依赖。
